# Chunky

Minecraft 区块预生成工具，支持 Spigot、Paper、Fabric、Forge、NeoForge 和 Sponge 等多种服务端。

快速、高效、安全地预生成区块！

## 快速开始

- [安装指南](https://github.com/pop4959/Chunky/wiki/Installing)
- [预生成区块](https://github.com/pop4959/Chunky/wiki/Pregeneration)
- [命令参考](https://github.com/pop4959/Chunky/wiki/Commands)

新安装默认使用简体中文。若沿用旧配置文件，请将 language 设置为 zh_CN。

## 获取帮助

如有关于 Chunky 的问题，请先查阅[官方 Wiki](https://github.com/pop4959/Chunky/wiki)，确认是否已有解答。

如果仍未找到答案，可以加入 [Discord 服务器](https://discord.gg/ZwVJukcNQG) 的 #chunky 频道寻求帮助。
